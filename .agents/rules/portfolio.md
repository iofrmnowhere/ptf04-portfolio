# Portfolio Design & Constraints
* **Aesthetic**: Strictly adhere to an "Avant Basic" design system. The layout must be clean and professional, featuring subtle pastel accents, distinct modern borders, and trendy geometric UI elements. 
* **Layout Structure**: Avoid visual clutter to prioritize readability. Ensure consistent navigation (top navbar or clean sidebar) across all pages.
* **Privacy Objective**: NEVER include sensitive personal information, real phone numbers, or real addresses in the generated code or placeholders.
